# Functional Requirements

## FR1 – User Input

The system shall accept user information.

## FR2 – AI Generation

The system shall generate an AI-assisted fitness plan.

## FR3 – Database

The system shall store user and plan information.

## FR4 – Feedback

The system shall accept feedback.

## FR5 – Updated Plan

The system shall generate an updated plan based on feedback.

## FR6 – User Records

The system shall display stored user records.
