# User Manual – FitBuddy-AI

## 1. Introduction

This user manual explains how to use the FitBuddy-AI web application.

FitBuddy-AI provides general wellness features for adults, including AI-generated workout examples, healthy eating examples, and BMI calculation.

---

## 2. System Requirements

The user needs:

- Windows, Linux, or macOS
- Python installed
- Internet connection
- Modern web browser
- Gemini API key configured by the application administrator

---

## 3. Starting the Application

Open a terminal in the FitBuddy-AI project folder.

Run:

```powershell
uvicorn app.main:app --reload
