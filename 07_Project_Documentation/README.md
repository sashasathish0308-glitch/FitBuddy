# Phase 7 – Project Documentation

## Project Name

FitBuddy-AI – AI-Powered Fitness and Wellness Planner

## 1. Introduction

This phase contains the complete documentation of the FitBuddy-AI project.

The documentation explains the project purpose, features, system design, implementation, installation process, and usage instructions.

## 2. Purpose

The purpose of this documentation is to provide a clear reference for understanding, installing, using, testing, and maintaining the FitBuddy-AI application.

## 3. Documentation Contents

This phase contains the following documents:

- Project Report
- User Manual
- Technical Documentation
- Installation Guide

## 4. Project Overview

FitBuddy-AI is a web-based wellness application developed using Python and FastAPI.

The application uses Google Gemini AI to generate general workout and healthy eating examples for adult users.

The project also provides a BMI calculator and uses SQLite for storing user and plan information.

## 5. Main Features

- Adult user profile creation
- AI-generated workout plans
- AI-generated healthy eating plans
- BMI calculation
- SQLite database
- Gemini AI integration
- FastAPI backend
- Web-based frontend
