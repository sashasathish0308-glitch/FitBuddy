# FitBuddy – AI Fitness Plan Generator

## 📌 Project Overview

FitBuddy is an AI-powered adult wellness planning application that generates general workout and healthy eating plans based on user-provided preferences.

The application uses Generative AI through Google's Gemini API and provides a simple web interface for generating personalized examples.

## 🎯 Project Objective

The main objective of FitBuddy is to demonstrate how Generative AI can be integrated with a web application to generate general wellness plans.

## ✨ Features

- 🤖 AI-generated workout plans
- 🍲 AI-generated diet plans
- 🧮 BMI calculator
- 🌐 Web-based user interface
- 🔌 FastAPI backend
- 🧠 Google Gemini AI integration
- 💾 SQLite database
- 📚 Swagger API documentation
- 🧪 API testing support
