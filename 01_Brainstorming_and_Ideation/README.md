# Phase 1 – Brainstorming and Ideation

## Project Title

FitBuddy – AI Fitness Plan Generator using Gemini Models

## Problem Statement

Users may find it difficult to create a structured fitness plan according to their personal goals and preferences.

## Proposed Solution

FitBuddy is an AI-powered web application that uses Generative AI to create a structured fitness plan from user-provided information.

## Main Idea

The application collects user information and sends the required information to the AI model.

The AI generates a structured fitness plan.

The generated result is displayed through a web interface.

## Main Features

- User input
- AI-generated fitness plan
- Nutrition/recovery tip
- Feedback-based plan update
- Database storage
- User record viewing

## Technologies

- Python
- FastAPI
- Gemini API
- SQLite
- SQLAlchemy
